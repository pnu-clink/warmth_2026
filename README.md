# Anonymous review software

Read **README.txt** for the current split-archive instructions. Extract the
Software and Data archives into the same directory before verification or
numeric reproduction. Human annotation files are intentionally withheld.

The preserved historical research scripts have not been modified. Use
`scripts/reproduce_available.py` for the released 12-cell Steering comparisons,
composite-score sensitivity, error counts, and saved KL summaries. The legacy
`scripts/reproduce_summaries.py` still expects withheld human labels and is not
the entry point for this partial release.
